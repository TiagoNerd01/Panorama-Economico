# PanoramaEconomico

Uma plataforma de consulta e análise econômica que apresenta indicadores de diferentes países, acompanha ativos financeiros e compara os dados observados com as expectativas negociadas em mercados de previsão.

## Status do projeto

Este projeto está em desenvolvimento. A estrutura inicial está organizada em controladores, rotas e serviços, mas os arquivos de código estão vazios no momento. Portanto, os endpoints e as funcionalidades descritos como objetivo ainda não estão implementados.

## Tecnologias

- Node.js
- Express 5
- dotenv
- Nodemon (dependência de desenvolvimento)

## Estrutura

```text
src/
├── controllers/  # Controladores da API
├── routes/       # Rotas da API
├── services/     # Integrações e serviços de domínio
└── server.js     # Ponto de entrada previsto para o servidor
```

## Instalação

É necessário ter Node.js e npm instalados.

```bash
npm install
```

## Execução

Os comandos `npm start` e `npm run dev` ainda precisam ser ajustados: atualmente, eles apontam para arquivos de entrada que não existem na raiz do projeto (`server.js` e `index.js`, respectivamente).

## Objetivos

- Consultar indicadores econômicos de diferentes países.
- Acompanhar ativos financeiros.
- Comparar dados observados com expectativas de mercados de previsão.
- Reunir informações em relatórios e análises econômicas.
